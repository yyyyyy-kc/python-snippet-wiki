物件導向 / Class #01

Python Class 核心用法與觀念筆記

核心心得與功能說明

Class 必須透過 __init__ 進行初始化賦值[cite: 2]。呼叫時（如 a.method(b)）會自動將 a 傳入 self、b 傳入 other[cite: 2]。透過 isinstance() 可以安全檢查物件型態[cite: 2]。另外，子類別可以使用 super().method() 輕鬆繼承父類別的方法，並透過同名覆寫（Override）來自訂行為，不需要重複編寫相似代碼[cite: 2]。

輸入與輸出範例

Input: v1 = Vector(2, 3); v2 = Vector(4, 5); v3 = v1 + v2
Output: Vector(6, 8) (利用 __add__ 內建方法實現)[cite: 2]
vector_demo.py 
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # 對應 + 運算子的內建 method
    def __add__(self, other):
        if isinstance(other, Vector):
            return Vector(self.x + other.x, self.y + other.y)
        raise TypeError("Unsupported operand type")

class SpecialVector(Vector):
    def __init__(self, x, y, label):
        super().__init__(x, y)
        self.label = label

    # 覆寫 (Override) 父類別的方法
    def __add__(self, other):
        res = super().__add__(other)
        return SpecialVector(res.x, res.y, self.label)
命令列與系統 / sys #02

使用 sys 模組接收命令列參數

核心心得與功能說明

透過 import sys 可以直接從終端機以單行指令讀取傳入的參數[cite: 2]。利用 sys.argv 進行切片，其中 sys.argv[0] 是當前執行的檔名，而 sys.argv[1:] 則是後續帶入的所有參數列表[cite: 2]。此外，在任何迴圈或深層邏輯中，都可以隨時呼叫 sys.exit() 來安全中斷整個程式的運行[cite: 2]。

輸入與輸出範例

Terminal: python script.py arg1 arg2
Output: Arguments received: ['arg1', 'arg2']
sys_demo.py 
import sys

def main():
    # 檢查是否有傳入參數
    if len(sys.argv) < 2:
        print("Error: 請提供至少一個參數！")
        sys.exit(1) # 中斷程式運行
        
    script_name = sys.argv[0]
    parameters = sys.argv[1:]
    
    print(f"正在執行檔案: {script_name}")
    print(f"收到的參數列表: {parameters}")

if __name__ == "__main__":
    main()
