物件導向 / Class #01

Python Class 核心用法與觀念筆記

核心心得與功能說明

我一開始最搞不懂 self 是誰，後來想通了：寫 a.method(b) 就等於呼叫 Class.method(a, b)，Python 會自動把 a 塞進 self、b 塞進 other。只屬於某個物件的變數，我一定在 __init__ 裡用 self.x = ... 設好。檢查型態我習慣用 isinstance(物件, 類別)，因為它連子類別也算。繼承時我會用 super().method() 沿用父類別的功能，但記得括號裡不用再寫 self，也只傳父類別有的參數。

輸入與輸出範例

Input: print(Vector(2, 3) + Vector(4, 5))
Output: Vector(6, 8)
vector_demo.py 
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # v1 + v2 會自動呼叫 __add__，v1 是 self、v2 是 other
    def __add__(self, other):
        if isinstance(other, Vector):
            return Vector(self.x + other.x, self.y + other.y)
        raise TypeError("Unsupported operand type")

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

print(Vector(2, 3) + Vector(4, 5))  # Vector(6, 8)
命令列與系統 / sys #02

使用 sys 模組接收命令列參數

核心心得與功能說明

我的記法是：sys.argv[0] 是檔名，sys.argv[1:] 才是我真正傳進去的參數。踩過的坑是參數全都是字串，要拿來算數字一定得先 int()。參數不夠時我會直接 sys.exit("用法…")，不管藏在多深的迴圈裡都能一次結束整個程式，不用一層一層 return 出去。

輸入與輸出範例

Terminal: python sys_demo.py foo 42
Output: foo 的兩倍是 84
sys_demo.py 
import sys

if len(sys.argv) < 3:
    sys.exit("用法: python sys_demo.py <名字> <數字>")

name = sys.argv[1]
try:
    n = int(sys.argv[2])  # argv 都是字串，要先轉 int
except ValueError:
    sys.exit("第二個參數必須是整數")

print(f"{name} 的兩倍是 {n * 2}")
物件導向 / 繼承 #03

銀行帳戶：transfer 的 return 與失敗計數

核心心得與功能說明

最容易丟分的是 transfer：裡面的 other.deposit(n) 雖然會 return True，但只回到 transfer 這一層，不會自動傳回主程式，所以後面一定要自己再寫 return True，不然會變 None。連續失敗次數要用兩個變數：fail 是目前連續失敗，成功取錢就歸零（存款不會歸零）；maxfail 記歷史最大值，不能重置。繼承的好處是 Savings 只要覆寫 lowest()，其他方法完全不用重寫。

輸入與輸出範例

Input: a = Account("amy", 120); b = Account("bob", 0); a.transfer(b, 50)
Output: True（a.balance = 70，b.balance = 50）
account_demo.py 
class Account:
    def __init__(self, owner, balance):
        self.owner, self.balance = owner, balance
        self.fail = 0      # 目前連續失敗，成功取錢就歸零
        self.maxfail = 0   # 歷史最大值，不會歸零

    def lowest(self):
        return 0

    def deposit(self, n):
        self.balance += n
        return True

    def withdraw(self, n):
        if n <= 0 or self.balance - n < self.lowest():
            self.fail += 1
            self.maxfail = max(self.maxfail, self.fail)
            return False
        self.fail = 0
        self.balance -= n
        return True

    def transfer(self, other, n):
        if self.withdraw(n):
            other.deposit(n)  # 這個 True 回不到主程式
            return True       # 一定要自己再 return
        return False

class Savings(Account):
    def lowest(self):         # 只覆寫下限，其他全繼承
        return 100
例外處理 / try-except #04

try / except 的順序與 else、finally

核心心得與功能說明

我現在都照「具體的放前面、籠統的放最後」來排 except，因為 Python 會從上往下比對，Exception 放太前面後面就永遠輪不到。只寫 except: 我絕對不用，它會連 KeyboardInterrupt、SystemExit 都吞掉，出錯了也找不到原因。else 是「沒出錯才執行」，finally 則是不管怎樣都會跑。

輸入與輸出範例

Input: safe_div("0")
Output: 不能除以 0 然後 無論如何都執行
try_demo.py 
def safe_div(s):
    try:
        n = int(s)
        q = 10 / n
    except ValueError as e:         # 具體的放前面
        print("不是整數:", e)
    except ZeroDivisionError:
        print("不能除以 0")
    except Exception as e:          # 最後才放籠統的
        print("其他錯誤:", type(e).__name__)
    else:
        print("沒出錯才執行:", q)
    finally:
        print("無論如何都執行")

safe_div("0")
排序 / sorted #05

sort 與 sorted，還有多條件排序

核心心得與功能說明

我考試時最常犯的錯是寫 x = x.sort()，結果 x 變成 None，因為 sort() 是原地排序、回傳 None；要新 list 就用 sorted()。排序永遠由小到大，數字想降序就在 key 加負號，像 key=lambda x: (-x[1], x[0]) 就是「分數高到低、同分名字 a 到 z」。但字串不能加負號，這時我會分兩次排（Python 的排序是穩定的）：先排次要條件，再排主要條件。

輸入與輸出範例

Input: [("b", 2), ("a", 2), ("c", 1)]
Output: [('a', 2), ('b', 2), ('c', 1)]
sort_demo.py 
nums = [3, 1, 2]
r = nums.sort()        # r 是 None，nums 變成 [1, 2, 3]
new = sorted([3, 1, 2])  # 回傳新 list，不動原本的

pairs = [("b", 2), ("a", 2), ("c", 1)]
# 數字高到低，同分再依名字 a → z
print(sorted(pairs, key=lambda x: (-x[1], x[0])))
